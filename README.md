# Smartphone Use Analysis

Navigate through a small dataset of smartphone users self-reported usage. Gain insight
into addiction levels and how that may affect sleep or productivity. 

Frontend: Vite+React, hosted on Vercel.
Backend: FastAPI, hosted on FastAPI Cloud; PostgreSQL database hosted on Neon.

## Attributions

Dataset comes from KaggleHub under Public Domain license. 
https://www.kaggle.com/datasets/algozee/smartphone-usage-and-addiction-analysis-dataset
